# Códice del Torneo

Fichas de movimientos de cada luchador: movimientos especiales, remates (fatalities, animalities, babalities, friendships, brutalities y stages), combos y las transformaciones de Shang Tsung.

## Qué tiene

- 35 luchadores, con vista **Ficha** (igual a las tarjetas) y vista **Lista**.
- Selector de control: **Sega**, **PlayStation** o **Xbox**, con botones personalizables.
- Favoritos de personajes y de movimientos.
- Descarga de cada ficha como imagen de tamaño estándar.
- Se instala como app en el celular y funciona sin internet.

Los favoritos y el control elegido se guardan en cada dispositivo.

## Cómo actualizar las fichas

Reemplazá `index.html` por la versión nueva (Add file → Upload files). Si querés que todos los celulares tomen el cambio enseguida, en `sw.js` cambiá `codice-v1` por `codice-v2` (y así sucesivamente).
